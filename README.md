# Data-for-stochastic-planning-of-standalone-energy-communities-extreme-weather-events-Brazil-Southern
Stochastic Planning of Standalone Energy Communities under Extreme Weather Events: A Case Study in Southern Brazil

Este conjunto de dados visa fornecer os parâmetros utilizados no método proposto, permitindo transparência e reprodutibilidade dos resultados. Além disso, apresenta um conjunto abrangente de figuras obtidas por meio da aplicação do método em diferentes cenários operacionais. O conjunto de dados inclui a geração fotovoltaica (PV) disponível, os perfis de estado de carga das baterias, o ajuste das distribuições nos dados, o corte de carga e o fluxograma do trabalho proposto. Todas as figuras são apresentadas em formato vetorial para garantir gráficos vetoriais de alta qualidade e visualização precisa.

Instruções: Conjunto de dados para fins de reprodutibilidade (.dat)

Agência de Fomento: Fundação de Amparo à Pesquisa do Estado de São Paulo (FAPESP) – Processo nº 2024/20610-2
